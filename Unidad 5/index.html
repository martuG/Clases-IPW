XML: el dato viaja en etiquetas

La nota de Juan para Ana es un documento XML. El XML guarda el dato. HTML lo muestra. El documento, solo, no dibuja la página.

Antes de empezar

Objetivos

El kiosco sigue siendo El Break. La nota del pedido ahora viaja en XML. Al terminar, deberían poder:

  • Explicar para qué se diseñó XML y qué puede hacer el documento por sí solo.
  • Separar el dato de la presentación: cambia el XML y JavaScript vuelve a escribir el HTML.
  • Leer el documento como árbol: raíz, padre, hijo, hermano, texto y atributo.
  • Reconocer el prólogo, el cierre obligatorio, las mayúsculas, el anidado y las comillas.
  • Nombrar un elemento con las reglas de XML y escribir un elemento vacío.
  • Decidir cuándo un dato conviene como elemento.
  • Separar dos elementos de igual nombre con un espacio de nombres.
  • Ver el XML tal cual y transformarlo en XHTML con XSLT.

Parte 1

1. XML guarda y transporta datos

XML significa lenguaje de marcado extensible. Se diseñó para almacenar y transportar datos, y para que una persona y un programa puedan leer el mismo texto. Se usa en muchos sistemas y, muy seguido, para repartir datos por Internet.

Una nota puede decir quién la manda, quién la recibe, cuál es el encabezado y cuál es el cuerpo. Con todo eso escrito, el documento no hace nada por sí solo. Es información envuelta en etiquetas. Un programa tiene que enviarla, recibirla, guardarla o mostrarla.

para

Quien recibe la nota. En el ejemplo, Ana.

de

Quien la manda. En el ejemplo, Juan.

encabezado

El título del mensaje. En el ejemplo, Pedido listo.

cuerpo

El texto. En el ejemplo, el café está en la barra.

<?xml version="1.0" encoding="UTF-8"?>
<nota fecha="12/11/2022">
  <para>Ana</para>
  <de>Juan</de>
  <encabezado>Pedido listo</encabezado>
  <cuerpo>El café está en la barra.</cuerpo>
</nota>

La primera línea es el prólogo. fecha es un atributo. El resto son elementos.

El botón lee el XML y deja el dato en texto. La nota no se dibuja sola.

Parte 2

2. El dato va en el XML. La página, en el HTML

En la web, XML se usa mucho para separar los datos de la presentación. El documento no dice el color ni el tamaño de la nota. Los mismos datos pueden mostrarse de distintas maneras.

XML suele completar a HTML. XML almacena o transporta el dato. HTML lo formatea y lo muestra. Si mañana la nota la manda Pedro, el HTML puede quedar igual: cambia el XML y unas líneas de JavaScript vuelven a escribir el contenido. 

const documento = new DOMParser().parseFromString(textoXml, "application/xml");
const nota = documento.documentElement;

nota.getAttribute("fecha");
nota.querySelector("para").textContent;

Parte 3

            
3. El documento es un árbol

            

                Un documento XML es un árbol de elementos. Empieza en un elemento raíz y se ramifica en elementos secundarios.
                Padre, hijo y hermano nombran las relaciones. Un padre tiene hijos. Un hijo tiene un padre.
                Los hermanos son hijos del mismo padre, en el mismo nivel.
            

            
Cualquier elemento puede tener texto y atributos.

            

                
nota · raíz · atributo fecha="12/11/2022"

                
    
                    
  • para — Ana
    • 
                    
  • de — Juan
    • 
                    
  • encabezado — Pedido listo
    • 
                    
  • cuerpo — El café está en la barra.
    • 
                

            

            

                

                    La nota, leída como árbol
                    
                        

                            Término
                            En este documento
                        

                    
                    
                        

                            Raíz
                            nota. El árbol tiene una sola.
                        

                        

                            Padre
                            nota es el padre de los cuatro elementos.
                        

                        

                            Hijos
                            para, de, encabezado y cuerpo.
                        

                        

                            Hermanos
                            Esos cuatro, entre sí.
                        

                        

                            Atributo
                            fecha. No es un hijo.

Parte 4

            
4. La sintaxis

            
Esta línea es el prólogo. Es opcional. Si está, va primero:

            
<?xml version="1.0" encoding="UTF-8"?>

            

                El documento puede traer caracteres internacionales, como la é de café.
                Conviene declarar la codificación, o guardar el archivo como UTF-8.
                UTF-8 es la codificación predeterminada.
            

            
    
                
  • Todo elemento se cierra. Un vacío puede usar autocierre: <br />.
    • 
                
  • Las mayúsculas importan. <Letra> y <letra> son dos nombres.
    • 
                
  • La apertura y el cierre se escriben igual.
    • 
                
  • Si un elemento se abre adentro de otro, se cierra adentro de ese otro.
    • 
                
  • El valor de un atributo va siempre entre comillas.
    • 
            

            

                En HTML a veces se ve <b><i>texto</b></i>.
                En XML, <i> se abrió dentro de <b> y tiene que cerrarse ahí:
                <b><i>texto</i></b>.
            

            

                
                
                
                
                
                
                
                
            

            
El botón escribe acá el XML que se está probando.

Parte 6

            
6. El atributo guarda un solo texto

            

                Un atributo es un par nombre/valor en la etiqueta de inicio, siempre entre comillas.
                Alcanza para un dato corto y estable, como la fecha escrita en una sola cadena.
                Cuando el dato crece, el elemento es el lugar.
            

            
    
                
  • Varios valores van en elementos repetidos. El atributo guarda un solo texto.
    • 
                
  • Un árbol de hijos vive en un elemento. El atributo no tiene hijos.
    • 
                
  • Sumar un dato nuevo es agregar un hijo. En el atributo hay que cambiar el formato del texto.
    • 
            

            

                

                    
Todo en atributos

                    
<nota fecha="12/11/2022" para="Ana Lucía">
  <de>Juan</de>
</nota>

                

                

                    
Los mismos datos como elementos

                    
<nota>
  <fecha>
    <dia>12</dia>
    <mes>11</mes>
    <anio>2022</anio>
  </fecha>
  <para>Ana</para>
  <para>Lucía</para>
  <de>Juan</de>
</nota>

                

            

            
            
El botón lee las dos formas con DOMParser.

        


        

            
Parte 7

            
7. Un prefijo evita que dos nombres choquen

            

                Los nombres de los elementos los elige quien escribe el XML.
                Si se mezclan dos documentos, el mismo nombre puede querer decir dos cosas.
                En El Break, mesa puede ser el número de la barra o un mueble del catálogo.
            

            

                El conflicto se evita con un prefijo. El prefijo se ata a un espacio de nombres
                con el atributo xmlns en la etiqueta de inicio.
                La dirección identifica el vocabulario. Esta página no llama a ese servidor.
            

            
<pedido xmlns:barra="http://elbreak.edu/barra"
        xmlns:mueble="http://elbreak.edu/muebles">
  <barra:mesa>4</barra:mesa>
  <mueble:mesa>roble</mueble:mesa>
</pedido>

            
            
Las dos se llaman mesa. El espacio de nombres las separa.

        


        

            
Parte 8

            
8. El navegador muestra el XML tal cual. XSLT lo transforma

            

                Los navegadores principales abren un archivo XML. Muestran el documento, con sus etiquetas.
                Eso todavía no es una página HTML, porque el XML no trae la presentación.
            

            

                Las etiquetas las inventa quien escribe el documento. El navegador no puede saber si
                <table> es una tabla de HTML o una mesa. Sin una indicación de cómo mostrar los datos,
                deja el documento como está.
            

            

                Para convertirlo en una página se usa XSLT: Extensible Stylesheet Language Transformations.
                Es un lenguaje para transformar XML. Una plantilla puede producir XHTML, u otro documento XML.
            

            
<xsl:stylesheet version="1.0"
  xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  <xsl:template match="/">
    <article>
      <h3><xsl:value-of select="nota/encabezado"/></h3>
      <p>Para <xsl:value-of select="nota/para"/>.
         De <xsl:value-of select="nota/de"/>.</p>
      <p><xsl:value-of select="nota/cuerpo"/></p>
    </article>
  </xsl:template>
</xsl:stylesheet>

            

                match="/" es la plantilla de la raíz del documento.
                xsl:value-of toma el texto de un elemento.
            

            

                
                
            

            

                
La transformación aparece acá.

            

            

                El archivo descargado, abierto en el navegador, se ve con sus etiquetas.
                El botón de XSLT lo convierte en el ticket.
