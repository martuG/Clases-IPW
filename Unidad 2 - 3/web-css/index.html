CSS: el lenguaje de la presentación

HTML describe qué es cada parte de la página. CSS describe cómo se ve. En esta materia van en archivos separados.

index.html + styles.css

Antes de empezar

Objetivos de la clase

  • Explicar el rol de CSS y por qué se separa del HTML.
  • Escribir reglas con selectores y declaraciones.
  • Usar selectores de elemento, clase, identificador y algunos combinadores.
  • Aplicar colores, tipografía, fondos y unidades.
  • Entender cascada, herencia y especificidad a nivel introductorio.
  • Mantener un archivo styles.css vinculado desde index.html.

Qué no entra hoy

El modelo de caja (margin, padding, border) y el diseño responsive tienen su propia web de clase.

1. ¿Qué problema resuelve CSS?

Sin CSS, el navegador muestra el HTML con estilos por defecto: títulos grandes, enlaces azules subrayados, párrafos negros, sin diseño de página. Alcanza para leer. No alcanza para construir una interfaz.

CSS permite una identidad visual, distribuir contenido, cambiar el diseño sin reescribir el HTML y reutilizar el mismo estilo en varias páginas.

Si cambio el CSS y no toco el HTML, ¿cambia el significado de la página? En principio, no. Sigue siendo un título o un párrafo. Cambia la presentación.

2. Tres formas de aplicar CSS (y cuál usar)

Forma Dónde se escribe ¿Se usa en la materia?
En línea style="" en un elemento No, salvo demostraciones
Interna <style> en el <head> No como práctica habitual
Externa archivo .css con <link> Sí: es la forma obligatoria 
<link rel="stylesheet" href="styles.css">

Esa línea va en el <head>. Si el nombre o la ruta están mal, la página se ve sin estilos: el HTML sigue funcionando, pero “desnudo”. Un mismo styles.css puede servir para index.html y contacto.html.

3. Sintaxis de una regla

h1 { color: #1a365d; }

  • selector a qué elementos aplica
  • propiedad qué se cambia
  • valor el resultado pedido
  • ; cierra la declaración
h1 {
    color: #1a365d;
    font-size: 2rem;
    text-align: center;
}
  • Cada declaración termina en punto y coma.
  • Las propiedades van en minúsculas y con guion: font-size, background-color.
  • La indentación es para personas, no para el navegador.
  • Comentarios: /* así */. CSS no admite // ni <!-- -->.

Todavía no hay selector aplicado.

Selector HTML CSS
Elemento <p> p { }
Clase (la más usada) class="destacado" .destacado { }
Id (único en la página) id="contacto" #contacto { }

En esta materia se prefiere clase para estilos. El id se reserva para anclas, formularios y casos puntuales. Un punto o una mayúscula de más y el selector no coincide.

6. Cascada, herencia y especificidad

Cuando varias reglas apuntan al mismo elemento, CSS decide cuál gana. Por eso se llama cascading.

Orden

Si la especificidad es la misma, gana la que aparece última.

p { color: black; }
p { color: navy; } /* esta prevalece */

Especificidad (versión introductoria)

  1. Elemento: p, h1
  2. Clase: .destacado
  3. Id: #contacto
  4. Estilo en línea: style=""
  5. !important (evitar)

Cuanto más específico es el selector, más difícil es de sobrescribir.

  1. ¿El archivo CSS está bien vinculado?
  2. ¿El selector coincide con el HTML? (mayúsculas, punto, #)
  3. ¿Otra regla más específica o posterior está ganando?

8. Unidades

Unidad Tipo Uso típico
px absoluta (en la práctica) Bordes, sombras, ajustes finos
% relativa al contenedor Anchos de columnas
em relativa al font-size del elemento Espaciados ligados al texto
rem relativa al font-size de html Tipografía y márgenes consistentes
vw / vh relativa al viewport Altos o anchos respecto de la ventana

En esta materia: rem para tipografía, porcentajes o rem para anchos, px para detalles.

11. Un archivo CSS ordenado

/* 1. Reset mínimo */
*, *::before, *::after { box-sizing: border-box; }

/* 2. Tipografía de body (se hereda) */
body { margin: 0; font-family: "Segoe UI", sans-serif; }

/* 3. Enlaces */
a:hover, a:focus { text-decoration: underline; }

/* 4. Componentes */
.boton { display: inline-block; padding: 0.6rem 1.2rem; }
  • Clases en minúsculas y con guion: .tarjeta-curso, no .tarjetaCurso.
  • Nombres de función (.aviso, .boton), no de apariencia rígida (.texto-rojo-grande).
  • Agrupar declaraciones repetidas en un mismo selector.

12. Errores frecuentes

  • href="styles.css" no coincide con el nombre o la carpeta.
  • class="destacado" en HTML y .Destacado en CSS.
  • Olvidar el punto de la clase o el # del id.
  • Olvidar el punto y coma: a veces se rompe toda la regla.
  • Usar style="" en cada etiqueta en lugar de clases.
  • Un id distinto para cada estilo, en vez de reutilizar clases.
  • Confundir font-size con el tamaño de la caja.
  • Poner el <link> en el <body> o con la ruta mal escrita.

13. Actividad práctica

Completar styles.css de la ficha personal. No se pide todavía responsive ni un estudio detallado de márgenes.

  • Vincular styles.css. Nada de estilos en línea ni <style>.
  • Tipografía y color en body para que hereden los demás.
  • Estilizar el h1 del encabezado.
  • Nav: sin subrayado; con subrayado en :hover y :focus.
  • Clase .tarjeta en un bloque del main.
  • Tabla: encabezados con fondo distinto al cuerpo.
  • Formulario: labels en bloque, inputs con borde, botón con .boton.

14. Preguntas de cierre

  1. ¿Qué ventaja tiene un CSS externo frente a los estilos en línea?

    Se reutiliza en varias páginas, el HTML queda legible y se puede cambiar el diseño sin tocar el contenido.

  2. ¿Cuál es la diferencia entre una clase y un id a la hora de escribir CSS?

    La clase (.destacado) se puede repetir y es la forma habitual de estilizar. El id (#contacto) es único, pesa más en la especificidad y se reserva para anclas o formularios.

  3. Si un p y un .destacado definen colores distintos, ¿cuál gana y por qué?

    Gana la clase: es más específica que el selector de elemento.

  4. ¿Qué propiedades se heredan y cuáles no?

    Se heredan color y font-family (también line-height). No se heredan margin, padding, border ni background.

  5. ¿Cómo verificarías en el navegador por qué una regla no se está aplicando?

    F12 → Inspector: revisar el vínculo del CSS, si el selector coincide, y qué regla aparece tachada porque otra más específica o posterior ganó.
