Modelo de caja y diseño responsive

Casi todo lo visible en una página es una caja. CSS controla su espacio interno, su borde y la distancia con las demás. Después, esa misma página tiene que funcionar en un celular, una tablet y una computadora.

Parte A · Modelo de caja

1. Las cuatro capas

Un párrafo, un título, un botón o un div ocupan un rectángulo. Ese rectángulo tiene cuatro capas, de adentro hacia afuera.

Para los alumnos · analogía del cuadro

  • El contenido es la pintura.
  • El padding es el paspartú (el marco interno en blanco).
  • El border es el marco de madera.
  • El margin es la distancia hasta el cuadro de al lado.

2. padding: espacio interno

El padding aleja el contenido del borde sin separar la caja de sus vecinas. Sin padding, el texto queda pegado al fondo. Con padding, la caja respira por dentro.

Sin padding

El texto está pegado al borde.

Con padding: 1.5rem

El texto está separado del borde. El fondo cubre ese aire.
padding: 16px;                 /* los cuatro lados */
padding: 16px 24px;            /* vertical | horizontal */
padding: 8px 16px 24px;        /* arriba | horizontal | abajo */
padding: 8px 16px 24px 32px;   /* arriba | derecha | abajo | izquierda */

El atajo recorre el sentido horario, empezando arriba. El padding no puede ser negativo.

3. border: el borde

Hace falta border-style para que se vea. Si falta el estilo, el ancho y el color no alcanzan.

4. margin: espacio externo

El margin separa cajas entre sí. No empuja el contenido hacia adentro: aleja un elemento de los demás. Con margin: 0 auto y un ancho definido, la caja se centra.

width: 70% + margin: 0 auto

Colapso de márgenes verticales

Entre dos bloques, los márgenes superior e inferior no siempre se suman. En flujo normal suele ganar el mayor. Eso se llama margin collapsing.

margin-bottom: 40px
margin-top: 24px

Lo esperado si se sumaran: 64px. Lo que suele verse: 40px (gana el mayor).

5. ¿Padding o margin?

Si el espacio debe llevar el mismo fondo que el elemento, es padding. Si el espacio debe ser calle entre elementos, es margin.

6. Ancho, alto y box-sizing

Por defecto (content-box), width es solo el contenido. Padding y border se suman afuera. Por eso dos columnas de 50% pueden no entrar en una fila.

Con border-box, width ya incluye padding y borde. En esta materia se usa en todos los proyectos. 

*,
*::before,
*::after {
    box-sizing: border-box;
}

Ambas cajas piden width: 220px, padding: 20px y border: 10px.

7. Cómo inspeccionar el modelo de caja

  1. Clic derecho sobre un elemento → Inspeccionar.
  2. En Computed aparece el gráfico del box model.
  3. Al pasar el cursor, el navegador colorea margin, border, padding y content.

Si una caja “no entra”, casi siempre el padding o el borde están sumando ancho, o un margin está empujando el layout.

Parte B · Diseño responsive

8. ¿Qué es diseño responsive?

Una misma página se reorganiza según el tamaño de la pantalla. No es un sitio aparte para celular: es un layout que fluye.

  • Evita texto ilegible o recortado.
  • Evita columnas de escritorio imposibles de usar en un teléfono.
  • Evita imágenes que fuerzan scroll horizontal.
  • Deja botones y menús usables con el dedo.

Pregunta disparadora

¿Responsive es lo mismo que “se ve bien en el celular”? Es una parte. También hay que pensar tablets y pantallas grandes. Por eso trabajamos mobile-first.

9. El viewport

Sin la meta etiqueta, muchos celulares simulan un escritorio de ~980px y luego escalan todo: el sitio se ve chico y hay que hacer zoom. Miren el chip de arriba a la derecha: muestra el ancho real de esta ventana. 

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Parte Significado
width=device-width El ancho de diseño coincide con el del dispositivo
initial-scale=1.0 No hay zoom inicial

11. Media queries y 12. Mobile-first

Una media query aplica CSS solo si se cumple una condición. Mobile-first: se escribe primero el CSS de la pantalla chica y se agrega complejidad con min-width. 

/* Base: una columna */
.columnas { display: block; }

@media (min-width: 768px) {
    .columnas { display: flex; gap: 1.5rem; }
}
Puntos de corte orientativos
Ancho Referencia
menos de 768px Celular
768px – 1023px Tablet
1024px o más Escritorio

El contenido dicta el corte: se ensancha la ventana hasta que el layout se rompe, y ahí se escribe la query.

14. Cómo probar y 15. Errores frecuentes

  1. Abrir la página en el navegador (no alcanza con el preview chico del editor).
  2. F12 → modo dispositivo. Probar 360, 768 y 1280.
  3. Comprobar que no haya scroll horizontal.
  4. Leer el texto y tocar los botones: tienen que seguir siendo usables.
  • Olvidar la meta viewport.
  • Poner width: 1200px al body o a las columnas.
  • Imágenes sin max-width: 100%.
  • Quedarse en content-box y no entender por qué 50% + 50% no entra.
  • Confundir padding con margin y “arreglar” espacios a ciegas.
  • Mezclar min-width y max-width sin criterio.

16. Actividad práctica

Tomar la ficha personal y convertirla en una página responsive. Entrega: index.html + styles.css.

Modelo de caja

  • box-sizing: border-box en todos los elementos.
  • Contenedor centrado: width: 90%, max-width, margin: 0 auto.
  • Un bloque con fondo donde se note padding vs margin.
  • Borde visible en tarjetas o formulario.
  • Imágenes fluidas.

Responsive

  • Meta viewport presente.
  • Pantalla chica: una columna y navegación vertical.
  • Desde 768px: dos columnas o menú en fila.
  • Sin scroll horizontal en 360px.
  • Media queries con min-width (mobile-first).

17. Preguntas de cierre

  1. ¿Qué parte del modelo de caja hereda el color de fondo: padding o margin?

    El padding. El margin es transparente y deja ver el fondo del padre.

  2. ¿Por qué dos cajas con width: 50% pueden no entrar en una misma fila?

    En content-box el padding y el border se suman al 50%. El total supera el 100%.

  3. ¿Qué problema concreto resuelve box-sizing: border-box?

    Hace que width incluya padding y borde, así el tamaño pedido es el tamaño real de la caja.

  4. ¿Qué ocurre en un celular si falta la meta viewport?

    El navegador simula un escritorio ancho y escala la página: se ve pequeña y hay que hacer zoom. Las media queries no se comportan como se espera.

  5. ¿Qué diferencia hay entre min-width y max-width?

    min-width agrega estilos desde cierto ancho hacia arriba (mobile-first). max-width aplica solo por debajo de un tope (desktop-first).

  6. Si el espacio entre dos títulos “no se suma”, ¿qué puede estar pasando?

    Colapso de márgenes verticales: entre bloques en flujo normal suele quedar el mayor, no la suma.
