En JavaScript se pueden desarrollar funciones. Una función es un bloque de código diseñado para realizar una tarea en particular. Una función de JavaScript se ejecuta cuando "algo" la invoca.

Una función de JavaScript se define con la palabra clave function, seguida de un nombre , seguido de paréntesis (). Los nombres de funciones pueden contener letras, dígitos, caracter de subrayado y signos de dólar. Los paréntesis pueden incluir nombres de parámetros separados por comas por ejemplo ( parámetro1, parámetro2, ... ). Veamos algunos ejemplos con funciones en el siguiente enlace.
