1. Un objeto guarda muchos valores

Un objeto también se guarda en una variable. Adentro puede haber varios datos. Cada dato es un par nombre: valor. El nombre y el valor se separan con dos puntos. 

const producto = {
  nombre: "café",
  precio: 1800,
  disponible: true
};

producto es una variable. Adentro hay tres pares. typeof producto es "object".

Clase 10 · Parte 3

3. Casi todo es un objeto

Un valor primitivo no tiene propiedades ni métodos. 3.14 es un primitivo: es el número, y nada más. Todo lo demás es un objeto.

JavaScript define 7 primitivos:

  • string
  • number
  • boolean
  • null
  • undefined
  • symbol
  • bigint

Paso 1 / 7. En cada paso la variable se llama dato.

const dato = "café";

Valor: café

typeof dato → string

Primitivo: string

Con new, un primitivo pasa a ser objeto

Un booleano, un número o un texto siguen siendo primitivos si se escriben directo. Con la palabra clave new se crea un objeto que los envuelve.

El resultado de typeof aparece acá.

Estos son siempre objetos

Clase 10 · Parte 4

4. Un constructor es el molde

A veces hace falta un modelo para crear muchos objetos del mismo tipo. Ese modelo es una función constructora. Por convención, el nombre empieza con mayúscula. Los objetos se crean llamándola con new. 

function Producto(nombre, precio) {
  this.nombre = nombre;
  this.precio = precio;
}

const cafe = new Producto("Café", 1800);

Dentro del constructor, this es el objeto nuevo. this.nombre = nombre guarda el dato en ese objeto.

    6. Un método es una propiedad con una función

    Un método es una propiedad cuyo valor es una función. this apunta a un objeto, y cuál sea depende de cómo se invoque.

  local: "El Break",
  total: 2700,
  resumen: function () {
    return this.local + ": " + this.total;
  }

    Clase 10 · Parte 8

    8. Getter y setter

    ES5 (2009) agregó los accesores. Un getter corre código cuando se lee una propiedad. Un setter corre código cuando se escribe. Por fuera se usan como cualquier propiedad. 

    const cafe = {
  nombre: "Café",
  _precio: 1800,
  get precio() {
    return this._precio;
  },
  set precio(valor) {
    if (!Number.isFinite(valor) || valor < 0) {
      return;
    }
    this._precio = valor;
  },
  get etiqueta() {
    return this.nombre + " · " + this.precio;
  }
};

    El guion bajo de _precio es una convención: el dato igual se puede leer. El getter ofrece el nombre precio.

    Prueben un precio negativo: el setter puede rechazarlo.

    La etiqueta se arma cada vez que se lee.

    Clase 10 · Parte 9

    9. Los objetos heredan de un prototipo

    Todo objeto hereda propiedades y métodos de un prototipo. La cadena termina en Object.prototype.

    • Un Date hereda de Date.prototype.
    • Un arreglo hereda de Array.prototype.
    • Un objeto creado con el constructor Combo hereda de Combo.prototype.
    • Date, Array y Combo también heredan de Object.prototype.

    Agregar mesa.listo cambia un solo objeto. Agregar un método en el prototipo se lo da a todos los objetos de ese tipo: los que ya existen y los que se creen después. 

    function Combo(nombre) {
  this.nombre = nombre;
}

Combo.prototype.etiqueta = function () {
  return "Combo: " + this.nombre;
};

      10. Métodos de objeto que llegaron con ES5

      ECMAScript 5 (2009) sumó métodos para inspeccionar y proteger objetos. Object.defineProperty ya apareció al dejar precio en solo lectura. Object.getPrototypeOf es el que arma la cadena de la parte anterior.

      Los que más vamos a nombrar
      Método Para qué sirve
      Object.keys(obj) Nombres de las propiedades propias y enumerables.
      Object.getOwnPropertyNames(obj) Nombres propios, también los que no se enumeran.
      Object.defineProperty(obj, nombre, descriptor) Crea o ajusta una propiedad: si se puede escribir, enumerar o borrar.
      Object.getPrototypeOf(obj) Devuelve el prototipo de ese objeto.
      Object.create(proto) Crea un objeto cuyo prototipo es proto.
      Object.freeze(obj) Impide cambiar, agregar o borrar propiedades.
      Object.seal(obj) Impide agregar o borrar. Los valores que ya están se pueden cambiar.
      Object.preventExtensions(obj) Impide agregar propiedades nuevas.

      Clase 10 · Parte 11

      11. Una clase es una plantilla

      ES2015 (ES6) incorporó las clases. Una clase no es un objeto: es la plantilla con la que se crean objetos. En este ejemplo la clase se llama Articulo, para no mezclarla con la función Producto de la parte 4. El papel es el mismo. 

      class Articulo {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }
  describir() {
    return this.nombre + " · " + this.precio;
  }
}
      • El método especial se llama exactamente constructor.
      • Corre solo, cuando se hace new Articulo(...).
      • Ahí se inicializan las propiedades del objeto.
      • Si la clase no define constructor, JavaScript agrega uno vacío.

        El constructor corre al crear el objeto.

        Clase 10 · Parte 12

        12. Heredar con extends

        extends crea una clase que hereda los métodos de otra. La clase base se llama superclase o clase padre. super(...) llama a su constructor. 

        class Bebida extends Articulo {
  constructor(nombre, precio, tamano) {
    super(nombre, precio);
    this.tamano = tamano;
  }
  describir() {
    return super.describir() + " · " + this.tamano;
  }
}

        Cada botón crea un objeto y muestra describir().

        Clase 10 · Parte 13

        13. Un método static vive en la clase

        Un método estático se define en la clase. Se llama sobre la clase: Turno.reiniciar(). El objeto que sale de new Turno(...) no tiene ese método. 

        class Turno {
  constructor(cliente) {
    Turno.ultimo += 1;
    this.numero = Turno.ultimo;
    this.cliente = cliente;
  }
  static reiniciar() {
    Turno.ultimo = 0;
  }
}
Turno.ultimo = 0;

        Contador de la clase: 0

        El número de turno lo lleva la clase.

        Clase 11 · Parte 14

        14. HTML DOM

        El modelo de objeto del documento (DOM) es la interfaz con la que JavaScript lee y cambia el HTML. Cuando la página carga, el navegador construye un árbol de objetos.

        Elementos

        Cada etiqueta HTML es un objeto del árbol.

        Propiedades

        Un valor que se puede leer o escribir, como el texto de un párrafo.

        Métodos y eventos

        Un método hace una acción: agregar, borrar, buscar. Un evento avisa que algo ocurrió.

        Con ese modelo, JavaScript puede:

        • Cambiar elementos, atributos y estilos.
        • Agregar elementos y atributos, y borrar los que ya están.
        • Reaccionar a los eventos de la página y registrar otros.

   ├─ h3 "Carta"

      ├─ li "Café"

        Métodos que vamos a usar

        18. Nodos, colecciones y NodeList

        En el DOM, todo es un nodo:

        • El documento es un nodo de documento.
        • Cada elemento HTML es un nodo de elemento (nodeType 1).
        • El texto de adentro es un nodo de texto (nodeType 3).
        • Los comentarios son nodos de comentario. El nodo de atributo quedó obsoleto: hoy el atributo se lee en el elemento.

        El nodo de arriba del todo es la raíz. Cada nodo tiene un padre, salvo la raíz. Puede tener varios hijos. Los hermanos comparten padre.

        HTMLCollection

        getElementsByClassName y getElementsByTagName devuelven una HTMLCollection. Se parece a un arreglo y no lo es: Array.isArray da false. Está viva: si después se agrega un elemento que coincide, la colección crece sola.

        NodeList

        Un NodeList también es una lista de nodos. childNodes devuelve un NodeList. querySelectorAll también, y esa lista queda fija: no ve los elementos que se agregan después.
