El código va entre <script> y </script>. Hay tres lugares habituales. En esta materia el código de comportamiento vive en su propio archivo, igual que el CSS.

En el <head>

El navegador lo encuentra temprano. Si en ese momento busca un botón del <body>, ese botón todavía no existe.

Al final del <body>

Archivo externo

La forma de trabajo de la materia. El HTML enlaza el archivo y el código se reutiliza.

Funciones y eventos, en una frase

Una función es un bloque de código con nombre. Un evento es algo que ocurre en la página, por ejemplo un clic. El botón del cartel, al recibir el clic, invoca una función.

Parte 3

3. Cuatro formas de mostrar un dato

El mismo pedido se puede comunicar de cuatro maneras. Cada una llega a un lugar distinto.

console.log()

Escribe en la consola del navegador. Esta caja la imita, y el mismo texto sale en la consola real (F12 o Ctrl+Shift+J).

window.alert()

Abre un cuadro del navegador. La página queda frenada hasta que se acepta. alert() es la misma función, guardada en window.

Avísenle a la clase antes de hacer clic: va a aparecer un cuadro modal.

innerHTML y textContent

innerHTML escribe dentro de un elemento e interpreta etiquetas. textContent escribe el texto tal cual.

document.write()

Escribe en el documento. Si la página ya cargó, reemplaza el documento entero. Por eso la prueba vive en una mini página, y esta clase sigue en su lugar.

Parte 4

4. Sentencias y declaraciones

Un programa es una lista de instrucciones. En un lenguaje, esas instrucciones se llaman sentencias. Una declaración arma un dato con valores, operadores, expresiones, palabras clave y comentarios.

let total = precio * 2 // dos cafés

  • let palabra clave
  • total nombre
  • = * operadores
  • precio * 2 expresión
  • // comentario
Las piezas de una declaración
Pieza En el ejemplo Qué es
Valor 2, "café", true Un dato literal: número, texto o sí/no.
Operador =, * Un símbolo que opera: guarda, suma, multiplica.
Expresión precio * 2 Un trozo que produce un valor.
Palabra clave let, const, function, return Una palabra con un significado fijo en el lenguaje.
Comentario // dos cafés Una nota para quien lee. El navegador la saltea.

5. Sintaxis

La sintaxis es la forma correcta de escribir. Estas reglas evitan los errores típicos de la primera clase.

Mayúsculas y minúsculas

total y Total son dos nombres distintos. let va en minúscula. Let es un error.

Nombres

Letras, dígitos, _ y $. El primer carácter es una letra, _ o $. Un nombre puede ser precioCafe.

Punto y coma y espacios

El ; cierra la sentencia. Conviene escribirlo. Los espacios y los saltos de línea ordenan la lectura; el navegador igual entiende el código si están bien puestos los símbolos.

Textos y bloques

El texto va entre comillas: "El Break". Un bloque de varias líneas va entre llaves { }.

Parte 7

7. Variables

Una variable es un nombre para un valor que el programa necesita recordar. En JavaScript hay cuatro formas de crearlas.

Cómo se declara
Forma Ejemplo del kiosco Qué conviene recordar
let let stock = 12; Se puede reasignar. Vive dentro del bloque { } donde se declaró. Es la opción habitual cuando el valor cambia.
const const kiosco = "El Break"; El nombre queda atado a ese valor: reasignarlo produce un error. Sirve para nombres que en el programa se mantienen.
var var legacy = 1; Es la forma histórica. Se puede redeclarar y su alcance es la función entera, también adentro de un bloque. En código nuevo usamos let y const.
Sin palabra clave precio = 1800; En modo normal crea una variable global, visible en toda la página. Con "use strict" la línea lanza un error. Siempre declaramos.

9. Operadores aritméticos

Operan con números. El decimal se escribe con punto: 2.4. JavaScript tiene un solo tipo numérico: 2 y 2.4 son number.

La cuenta del pedido

La multiplicación se resuelve antes que la suma: precio * cantidad de cada producto, y después se suman.

Los paréntesis cambian el orden

Elijan una cuenta.

El + hace dos trabajos. Entre números, suma. Si alguno de los dos es texto, los une. Por eso "2" + 2 da el texto "22", y "2" * 2 da el número 4.

El resto: medialunas que no llenan una caja

% devuelve lo que sobra de una división entera. / dice cuántas cajas, contando la fracción.

Parte 12

12. Funciones

Una función es un bloque de código con una tarea. Se define con la palabra clave function, un nombre y paréntesis. Los paréntesis pueden llevar parámetros, separados por comas. La función corre cuando algo la invoca: otra línea, o un evento. 

function cobrar(cafes, medialunas) {
  const total = cafes * 1800 + medialunas * 900;
  return total;
}

const importe = cobrar(2, 3);
  • cobrar es el nombre. Puede llevar letras, dígitos, _ y $.
  • cafes y medialunas son los parámetros: los datos que llegan.
  • return devuelve el total a quien la llamó.
  • La última línea es la invocación. Recién ahí se ejecuta el cálculo.

Esta página ya definió cobrar al cargar. Invocaciones hasta ahora: 0.

El saludo y el total aparecen acá. El contador sube cuando la función se ejecuta.

El clic es el “algo” que la invoca

En script.js, el botón escucha el evento click y, dentro de esa función, llama a cobrar. Definir la función y apretar el botón son dos momentos distintos.
